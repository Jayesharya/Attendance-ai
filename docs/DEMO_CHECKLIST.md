# Local demo checklist

## Before the session

- Install the pinned dependencies from requirements.txt.
- Run the test suite with python -m unittest discover -s tests -v.
- Run the app with python -m streamlit run app.py.
- Confirm the browser can record audio if that workflow will be shown.
- Confirm OpenCV can open the intended local camera.
- Use a short prerecorded clip if the webcam is unavailable.
- If demonstrating local AI prompts, make sure an Ollama model is already installed and running.
- Set expected class size only when you have a reasonable roster count.

## During the session

- Explain that the system uses anonymous face boxes and no identity recognition.
- Tell participants whether room audio is being analyzed.
- Keep the duration short and inspect the lighting and framing.
- Treat activity indicators and roster coverage as estimates.
- Review suggested teaching prompts in context.

## After the session

- Save a report only if it is useful for the demo.
- Download CSV/PDF exports if needed.
- Clear local history when you no longer need the reports.
- Close or refresh the page to clear active session previews and uploads.
